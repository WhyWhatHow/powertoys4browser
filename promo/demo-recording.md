# 🎬 演示 GIF 录制方案

> 为什么做 GIF:这两个脚本的卖点都是"看得见的变化", 15-30 秒演示比任何文案转化都高。
> 目标产物:每条 **≤30s, 1280px 宽, 8-10fps, 1-3MB** 的 GIF(直播后可直接发 X/README/贴吧)。

---

## 一、工具链(WSL 环境)

- **录制**:Windows 侧推荐 **Win + G 调出 Xbox Game Bar**(免费自带, 无需安装),或 [OBS](https://obsproject.com) 选区录制
  - 浏览器建议用 **Chrome 无痕窗口**登录 X(避免个人隐私入镜,演示完即关)
- **转 GIF**:WSL 内已装 `ffmpeg 6.1`, 命令见下
- 备选 WSLg 录屏:`ffmpeg -f x11grab`(桌面会话可显示时用, 不稳则用 Game Bar)

## 二、Minimal Twitter 演示(主推 before/after 结构)

> 目标:让观众 3 秒内看懂"装前 vs 装后"。

**分镜(总时长 ~25s):**

| 时间 | 画面 | 动作 |
| --- | --- | --- |
| 0-5s | 未启用脚本的 X 首页 | 慢速滚动时间线, 展示左侧导航拥挤(带标签、Premium/Grok 一堆入口) |
| 5-6s | 同一页面 | Tampermonkey 菜单点开 → 启用脚本 |
| 6-20s | 启用后 | 缓慢滚动: 左侧导航变纯图标; 鼠标悬停导航 → 标签滑出; 进入设置面板关掉 Grok 抽屉开关再开回来 |
| 20-25s | 结尾定格 | 停在干净的首页 + 左上角叠加文字"Minimal Twitter" |

**要点:**
- 右上角悬浮设置按钮点开后滑过三语切换, 是中文观众最有共鸣的镜头
- 无痕窗口 + 鼠标移动慢一点, 方便观众跟随

## 三、X Comment Bot Blocker 演示(主推"扫描+屏蔽"过程)

> 目标:展示三维匹配的威力 + 防误伤设计(诚实人设也是卖点)。

**分镜(总时长 ~30s):**

| 时间 | 画面 | 动作 |
| --- | --- | --- |
| 0-4s | 一条流量推文的评论区 | 滚动展示: 一堆"约炮加微信""同城上门"式回复 |
| 4-8s | 面板 | 点击 [+ 选取评论] → 点一条 bot 评论作为模板 |
| 8-10s | 面板 | 取消勾选"自动"(保持仅标记) |
| 10-22s | 扫描过程 | 点 ▶ 扫描, 面板统计跳动, 评论区疑似评论被红框高亮; 快进感可用 2x 剪辑 |
| 22-26s | 复盘 | 打开 ⚙→数据→屏蔽记录, 展示命中原因与时间 |
| 26-30s | 结尾 | 面板"已屏蔽 N 个账号"定格 + 文案"试运行防误伤 · 误封可一键解封" |

**要点:**
- 一定要演示"仅标记"模式(诚实人设, 回应误封顾虑)
- 结尾停在屏蔽记录页 = 观众看到"可追溯可解封", 打消担忧

## 四、ffmpeg 转 GIF(两遍调色板法, 画质最好)

```bash
# 先把录制好的 mp4 裁剪到 30s 内
ffmpeg -i demo.mp4 -t 30 -vf "scale=1280:-1,fps=10" -c:v libx264 -crf 23 demo-cut.mp4

# 第一遍:生成调色板
ffmpeg -i demo-cut.mp4 -vf "fps=10,scale=1280:-1:flags=lanczos,palettegen" palette.png

# 第二遍:套调色板输出 GIF
ffmpeg -i demo-cut.mp4 -i palette.png -lavfi "fps=10,scale=1280:-1:flags=lanczos[x];[x][1:v]paletteuse" demo.gif
```

体积检查:`ls -lh demo.gif`, 若 >3MB 把 `fps=10` 降到 `fps=8` 或宽度降到 960。
